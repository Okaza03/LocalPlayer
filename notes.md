# Valo v0.5.1

Watch progress is kept per user.

### Fixed
- **Each user has their own Continue watching and My list.** They were saved per server only, so after signing in as someone else on the same device you saw the previous user's progress, and it was sent to the new account. Now every user of a server gets their own, on the desktop and on the TV.

If your progress got mixed up between two accounts, sign in as the account that should start fresh and use Settings, Watch history, Clear on the desktop. That resets its progress on the server too.
