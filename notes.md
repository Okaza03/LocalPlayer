# Valo v0.5.2

A new desktop icon, cleaner focus on the TV, and AppImage updates that keep the version in the file name.

### Changed
- **New desktop icon:** the logo in white on a black circle, so it's easy to see on light and dark taskbars alike. On Linux the app menu picks it up the first time this version starts.
- **TV: clearer focus.** The button the remote is on turns white, grows a little and glows. It no longer gets an outline drawn inside it, and it's easy to tell apart from the selected tab or filter.
- **AppImage updates rename the file.** When the AppImage updates itself, a file named with its version (`valo-v0.5.2-x86_64.AppImage`) becomes the next version's name and the old file is removed. A name without a version, like `valo.AppImage`, is kept. This starts with the update after this one.
